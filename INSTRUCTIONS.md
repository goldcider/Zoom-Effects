--- Instructions --

1) Download the required .bat files for your chosen device and effect category.

2) Create a local folder to download the files into.

3) Run the .bat file inside the local folder (this will open a terminal that will begin downloading and extracting the .zip files for the effects into their own sub-folders).

4) Use the .ZD2 / .ZIC / .ZIR files with zoom-zt2 to add to your device.

If you are after specific individual effects then you must find the line inside the .bat file that has the specific curl query for that effect and either copy & paste it into your command prompt and run it individually or delete the other lines from the .bat file, save the file and then run it inside your folder as previously stated.

Each device has a limit to the number of effects that they can hold, it is worth searching the storage limit for the number of effects that your device can hold and removing any that you do not use to make room for ones you will use instead.
